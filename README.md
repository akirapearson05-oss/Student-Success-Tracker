Student Success Tracker

Project Description

The Student Success Tracker is a student-focused website designed to help organize and analyze academic progress. It displays course grade averages, study hours, and missing assignments to help students identify areas that may need improvement.

Features

Add student academic records

View overall average grades and study hours

Compare average grades by course

Visualize the relationship between study hours and grades

Track missing assignments by course

Display student success insights and recommendations

View and download student data as a CSV file

Technologies Used

Python

Streamlit

Pandas

Jupyter Notebook

CSS

How to Run

Make sure Python and the required libraries are installed.

Keep app.py and style.css in the same folder.

Open a terminal in that folder.

Run the command:

python3 -m streamlit run app.py

Open the local website link provided in the terminal.

Data

The project uses fictional sample student records for demonstration purposes. Records added through the website are temporary and are not permanently saved by the application.

Purpose

The purpose of this project is to demonstrate how student academic data can be collected, processed, analyzed, and presented in a useful dashboard.
